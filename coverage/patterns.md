# Question Design Patterns

1. **Threshold trap** — scenario gives specific numbers; ask whether threshold is met; distractors = adjacent thresholds.
2. **And/Or confusion** — rule "A OR B"; scenario satisfies only A; distractor reads as "A AND B" (or vice versa).
3. **Amendment trap** — distractor uses pre-amendment figure (e.g., old 75% CoC, old ₹1 L IBC, old 15% SAST trigger).
4. **Exception** — main rule applies on surface; scenario triggers exception; students who apply main rule fail.
5. **Cross-law confusion** — same number, different meaning across laws (see `cross-law-traps.md`).
6. **Sequential procedure** — ask FIRST/NEXT step; tests procedural order, not static rule.
7. **Negative knowledge** — "Which is NOT covered by Sec X"; one option falsely attributed to the section.
8. **Multi-party** — track A, B, C, D each with different obligations; ask which is in compliance.

**Hardness target:** every question must require scenario facts to be **transformed** (computed, compared to threshold, matched to exception). Reject any Q answerable from question text alone.

**Negative-framing share:** 30–40% across the set.

**Difficulty mix:** 60% Hard / 30% Very Hard / 10% Medium-Hard. Zero recall.
