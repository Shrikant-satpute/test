# Economic Laws Coverage

## FEMA 1999

| Sec | Topic | Tricky Points |
|---|---|---|
| 2(v) | Person Resident in India | >182 days in preceding **FINANCIAL YEAR** (Apr–Mar) — NOT calendar |
| 2(e) | Capital account txn | Alters assets/liabilities outside India (resident) or inside (non-resident) |
| 2(j) | Current account txn | Everything except capital |
| 3 | Prohibition on dealing | Only via authorised person |
| 4 | Holding outside India | Needs RBI permission |
| 5 | Current account | **Generally permitted**; CG may restrict |
| 6 | Capital account | **Prohibited unless permitted** by RBI |
| 7 | Export proceeds | Realise & repatriate within prescribed time |
| 13 | Penalties | Up to 3× sum (quantifiable); ₹2 L (non-quantifiable); ₹5,000/day continuing |
| LRS | Remittance | USD 2,50,000/person/FY |

**Traps:** FEMA 182 days = **financial year**; Companies Act resident director 182 days = **calendar year** — same number, different windows. Current account **permitted unless prohibited**; capital account **prohibited unless permitted** — students reverse. Non-quantifiable penalty = ₹2 L flat (not 3×).

**Scenarios:** 183-day stay Apr–Sep then leaves — resident status for next FY? Indian co. buys foreign shares — current or capital? 2-yr deputation abroad — residential status + property implications?

## FCRA 2010

| Sec | Topic | Tricky Points |
|---|---|---|
| 2 | Definitions | Foreign contribution = article/currency/security from foreign source |
| 3 | Prohibited persons | Political parties, candidates, govt servants, judges, legislators, **editors of newspapers** — cannot receive FC |
| 6 | Registration | MHA; org ≥3 yrs old + spent ≥**₹15 lakh** in 3 yrs |
| 8 | Management | Designated account: **SBI New Delhi Main Branch** (post-2020); admin expense cap **20%** |
| 11 | Prior permission | Alternative to registration for specific purpose |
| 18 | Intimation | Within 3 months of receipt |
| Relative threshold | ≥₹10 L from foreign source → Form FC-1 within 3 months |

**Traps:** Registration eligibility = ₹15 L **spent** (not received, not ₹10 L); admin cap **20%** post-2020 (old 50%); SBI **New Delhi Main Branch** specifically — any SBI branch ≠ sufficient; newspaper editors barred (not just "journalists").

## IBC 2016

| Sec | Topic | Tricky Points |
|---|---|---|
| 4 | Default threshold | **₹1 crore** (raised from ₹1 lakh in 2020) |
| 7 | FC application | No demand notice; NCLT admits/rejects within 14 days |
| 8 | OC demand notice | 21 days before filing; debtor must reply/pay in 21 days |
| 9 | OC application | After 21-day period; same ₹1 Cr threshold |
| 13 | Moratorium | Declared by NCLT **simultaneously** with admission |
| 14 | Effects of moratorium | No suits; no transfers; no security enforcement; **no recovery by lessor/owner** |
| 16 | IRP appointment | With moratorium; IRP takes over management |
| 21 | CoC | All FCs; OC with >10% may **attend not vote**; decisions **66% voting share** |
| 12 | CIRP timeline | 180 + 90 extension = 270; + litigation = **max 330 days** |
| 29A | Ineligible applicants | Defaulting promoters; wilful defaulters; NPA borrowers (1+ yr); **guarantors**; convicted persons |
| 30/31 | Resolution plan | CoC 66%; then NCLT sanction |
| 33 | Liquidation | If no plan / CoC chooses / NCLT rejects / plan violated |
| 53 | Waterfall | CIRP costs → workmen **24 months** + secured creditors → employees **12 months** → unsecured FCs → govt dues → preference → equity |
| 60 | Adjudicating authority | NCLT |

**Traps:** Default threshold **₹1 Cr** post-2020 (vs Companies Act inability-to-pay ₹1 lakh — see cross-law-traps); CoC **66%** (was 75% pre-2019); OC >10% may **attend not vote**; demand notice required for OC, **not FC**; moratorium is **simultaneous** with admission; workmen **24 months** vs employees **12 months**; Sec 29A includes **guarantors**.

**Scenarios:** FC + OC file together → CoC priority? Plan with 60% CoC → NCLT can sanction? (No.) Defaulting promoter joins consortium where he holds 49% — eligibility? CIRP 290 days + 50-day court stay → still under 330? Landlord wants to terminate lease during moratorium → barred?
